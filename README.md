# 坂戸・鶴ヶ島 コミュニティバス マップ

坂戸市（さかっちバス／さかっちワゴン 9路線）と鶴ヶ島市（つるバス／つるワゴン 7路線）のコミュニティバスを、1枚のインタラクティブな地図にまとめた単一ファイルの Web アプリです。

- 地図モード／路線図モード（地下鉄路線図風）の切り替え
- 全停留所を公式の運行順で表示、路線・停留所の詳細ページ
- 停留所検索（かな対応）、乗換案内、お気に入り
- ライト／ダーク／自動テーマ
- ピンチ・ダブルタップ・慣性スクロールなど、ネイティブの地図アプリに近い操作感

`index.html` をブラウザで開くだけで動きます（外部通信なし）。

## PWA

GitHub Pages などの HTTPS で公開すると、ホーム画面に追加してアプリとして使えます（iPhone は Safari の共有 →「ホーム画面に追加」）。一度開けばオフラインでも表示できます。

更新を公開するときは `sw.js` の `CACHE` の番号を上げてください（例：`busmap-v2`）。

## 構成

- `index.html` — ビルド済みのアプリ本体
- `manifest.webmanifest` / `sw.js` / `icons/` — PWA 用
- `src/` — HTML/CSS（head.html）、描画（core2.js）、UI（ui.js）、ビルドスクリプト
- `data/` — 路線ネットワーク（net_all.json）と背景地図（base.json）
- `tools/` — 路線データの生成・補正スクリプト（作業環境のパスに依存）
- `tests/` — Playwright による表示・操作チェック

再ビルド: `python3 src/build.py`

## 出典

坂戸市・鶴ヶ島市が公開している路線図 PDF をもとに作成しています。停留所の順序は公開時刻表情報を参照しました。時刻表は含みません。最新の運行情報は各市の公式サイトをご確認ください。
